# INTENT — compact 워크플로우 최초 작성

## INTENT

- 목적: 복잡한 기존 워크플로우를 대체할 단순하고 실용적인 기준을 작성한다.
- 범위: 네 단계 문서, 버전별 저장, 단계별 의도, 현재 도구 내 멀티에이전트 구성과 루트 참조 전환.
- 기대 결과: 사람과 에이전트가 같은 문서로 프로젝트를 수행하고, 루트 지침에서 새 기준을 참조한다.

## 배경

사용자는 기존 절차와 설정·하네스가 과도하다고 판단했다.
INTENT → DECISIONS → SPEC → PLAN으로 줄이고 `specs/{version}/`에 저장하기로 했다.
설계 템플릿은 하위 폴더 없는 네 문서, 단계별 INTENT는 문서 안의 독립 항목으로 선택했다.
사용자 후속 요청에 따라 Phase별 진행사항과 사용자 요청 작업 내역을 담는 PROGRESS.md를 추가한다.

## 제외 범위

기존 클론 수정, 개별 프로젝트 일괄 전환, 에이전트 도구 간 연결, 필수 실행 하네스 구축.
