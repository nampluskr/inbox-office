# Markdown Editor

## INTENT

Windows에서 로컬 폴더의 Markdown과 코드 원문을 열고, 직접 편집·저장하며 Markdown 결과를 확인하는 Rust 데스크톱 편집기를 만든다. GPUI를 화면 기반으로, GPUI Kit을 UI 구성 요소로 사용한다.

이 프로젝트의 핵심 목적은 GPUI Kit의 기존 구성 요소와 Sol·Terra 협업으로 빠르게 실행 가능한 앱을 만들 수 있는지 확인하는 것이다. MVP를 실제 빌드·실행하고 Kit 재사용 범위, 추가로 작성한 부분, 구현 소요와 의존성·제약을 기록한다. 제품 수준의 확장 구조를 먼저 만드는 대신 PLAN의 기능을 직접 연결해 검증한다.

폴더 목록에서 작업 대상을 바꾸고 파일 트리와 탭으로 문서를 다루는 흐름이 제품의 중심이다. Sidebar는 등록한 폴더 목록, Leftbar는 활성 폴더의 파일 트리를 뜻한다. 원문과 Preview를 오가도 편집 상태와 폴더별 작업 맥락을 유지해야 한다.

## 배경과 판단 기준

Zed의 화면 구성을 참고하되 필요한 문서 작업에 집중한다. 최종 시각 기준은 [Zed 레이아웃 이미지](docs/references/zed-layout.png)이며 이전 workbench-kit-ui 이미지를 대체한다. 이미지에 보이는 기능 전체를 요구하는 것은 아니다.

- 로컬 문서를 바로 편집하고 저장할 수 있는가.
- 저장 전 본문으로 Markdown 결과를 확인할 수 있는가.
- 폴더 전환과 재시작 후 필요한 작업 상태를 이어갈 수 있는가.
- 요구·확정 결정·제안·미정을 구분하고 실제 검증으로 완료를 판정할 수 있는가.

## 제외 범위

터미널, AI·스레드·로그인, 코드 빌드·실행·디버깅, PDF·CSV·이미지 편집, 독립 모듈 앱과 확장 설치는 제외한다. Markdown의 로컬 이미지 표시와 수식 렌더링은 포함하되 이미지 편집이나 별도 LaTeX 조판 앱으로 확대하지 않는다.

## 현재 단계

현재 버전은 `v0.1`이다. 사용자 최신 요청으로 MVP 구현·빌드·실행·검증까지 진행한다. main이 필요한 결정을 하고 이유를 기록하며 Sol이 PLAN에 따라 Terra와 협업한다. [버전 INTENT](specs/v0.1/INTENT.md), [PLAN](specs/v0.1/PLAN.md), [PROGRESS](specs/v0.1/PROGRESS.md)를 통해 설계와 실제 수행 상태를 구분한다. 이전 다목적 구상과 학습 문서는 사용자 요청에 따라 정리하고 현재 버전 문서를 기준으로 유지한다.
