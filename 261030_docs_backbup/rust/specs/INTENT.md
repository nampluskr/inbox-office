# Markdown Editor 의도

## INTENT

로컬 폴더에서 Markdown과 코드 파일을 탐색하고 원문을 바로 편집·저장하며, 저장 전 본문을 포함한 Markdown Preview를 확인하는 Windows 편집기의 범위를 정의한다. 기대 결과는 폴더별 작업 맥락을 유지하는 일관된 편집·미리보기 흐름이다.

최신 사용자 요청은 GPUI Kit으로 빠른 앱 생성 가능성을 검증하는 MVP 구현·빌드·실행이다. main이 DECISIONS의 U-1~U-10을 확정했고 Sol이 Terra와 PLAN 순서대로 구현한다. 프로젝트 전체 기준은 [루트 INTENT](../../INTENT.md)다. 실제 완료 여부는 검증 결과로 구분한다.

## 배경과 사용 흐름

1. Sidebar에서 로컬 폴더를 등록하고 활성 폴더를 선택한다. 등록 해제는 목록에서 제거하는 동작이며 디스크 폴더를 삭제하지 않는다.
2. Leftbar에서 활성 폴더의 트리를 탐색해 오른쪽 원문 탭으로 파일을 연다. 코드와 Markdown 구문을 강조하고 별도 모드 전환 없이 수정·저장한다.
3. Markdown Preview를 별도 탭 또는 오른쪽 분할로 열어 미저장 원문의 렌더링 결과를 확인한다.
4. 폴더를 전환하면 각 폴더의 탭과 선택 상태를 유지한다. 재시작하면 폴더 목록과 저장 파일 탭을 복원한다.
5. 미저장 변경이 있는 정상 종료에서는 저장·버리기·취소 중 선택한다.

## 화면과 문법 범위

최종 참고 이미지는 [zed-layout.png](../../docs/references/zed-layout.png)다. Sidebar는 가장 왼쪽 폴더 목록, Leftbar는 그 옆 활성 폴더 트리, 오른쪽은 탭 편집 영역이다. 하단 상태표시줄의 독립 아이콘으로 Sidebar와 Leftbar를 각각 표시하거나 숨기며 패널 크기 조절과 상태 복원을 지원한다.

Preview는 기본 Markdown 문법, 표, 작업 목록, 코드 강조, 상대 로컬 이미지·링크, 인라인·블록 수식을 포함한다. 문법·지원 언어·인코딩·Preview 연결과 갱신은 [DECISIONS](DECISIONS.md)의 확정 U-1~U-10을 따른다. 별도 탭과 오른쪽 분할을 모두 제공한다.

## 제외 범위

터미널, AI·스레드·로그인, 빌드·실행·디버깅, PDF·CSV·이미지 편집, 독립 모듈 앱과 확장 설치는 제공하지 않는다. 상단 메뉴에는 실제 구현한 기능만 노출한다. 이전 다기능 작업 도구 구상이나 학습 자료의 예제가 v0.1 요구를 확장하지 않는다.

## 완료 판단

제품 완료는 [SPEC](SPEC.md)의 요구별 판정 기준을 실제 구현에서 검증한 뒤 판단한다. 문서 작성 완료와 제품 완료는 [PROGRESS](PROGRESS.md)에서 별도로 기록한다. 현재는 앱 구현·실행·사용성·성능을 검증하지 않았다.
