## AGENTS 검토 의견

- 초기 AGENTS의 Sol 담당 목록에 AGENTS가 포함되어 있었으나 호출 담당이 실제 운영에 맞춰 수정했다. AGENTS·Herdr와 최종 통합은 호출 담당, 담당 문서 작성은 Sol·Terra로 구분한다.
- AGENTS의 일반적인 호출·통합 역할과 이번 D-1 작성 역할을 구분해야 한다. Herdr 제어와 최종 통합은 호출 담당 책임으로 유지한다.
- 이전 문서 보존·링크 갱신은 초기 D-1의 실제 수행 이력이다. 사용자 후속 요청으로 해당 문서를 삭제하고 AGENTS·안내를 최신 상태로 바꿨다. 과거 작업 이력은 위 표에 유지한다.

## 남은 사항

main이 최신 요청에 따라 DECISIONS의 U-1~U-10을 MVP 기준으로 확정했다. 과거 기록의 미정·문서 한정 승인은 당시 이력이다. 현재는 확정 정책을 적용하여 실제 빌드·기능 검증을 수행한다.

## 버전 종료

상태: 진행 중. 사용자 종료 판단은 없다. 현재 완료 범위는 문서 작성·협업 구성·이전 문서 정리와 문서 통합 검증이다. 앱 구현과 SPEC의 실제 기능 검증은 수행하지 않았고 버전 완료로 표시하지 않는다.

최신 상태: 위 문장은 문서 단계 종료 당시 이력이다. 현재는 MVP 구현 요청에 따라 소스와 앱 통합을 진행하며 기능 완료 판정은 후속 실제 결과로 갱신한다.

## 2026-10-30 — 최신 MVP 구현 요청 착수 / Phase 2 P-5~P-6

- 요청: GPUI Kit 빠른 앱 생성 가능성 검증을 목적으로 Sol 리드·Terra 협업으로 P-5~P-15를 구현·빌드·검증한다. main이 판단을 위임받아 U-1~U-10을 확정했으며 이전 문서 한정·사용자 승인 대기 지시는 대체되었다.
- 적용: 버전 INTENT·SPEC·PLAN·README를 동기화했다. 요구 R-1~R-14는 유지한다. Kit =0.8.1, 기본 component/assets, syntect와 Kit 선택 GPUI 조합을 사용한다.
- 소유권: PLAN에 파일별 경계와 EditorPane/PreviewPane 인터페이스를 기록했다. Terra에게 Herdr로 독립 편집·렌더링 및 MathJax 작업을 실제 전달했고 Terra가 배정과 EditorState API 조사 착수를 확인했다. Sol은 Cargo·작업 공간·파일 I/O·세션·문서 통합을 담당한다.
- 환경: HERDR_ENV=1 확인. 관리자 서버 접근 오류는 require_escalated로 해결하여 기존 specs-sol/specs-terra 상태를 조회했다. 서버 재시작·탭 종료 없음. cargo 1.99.1과 Node/Python 명령 존재 확인.
- 빌드 준비: 기본 권한 Cargo 조회는 TLS 자격 증명 오류, 승격 후 인증서 폐기 확인 서비스 오류. 이번 Cargo 호출의 http.check-revoke=false로 인증서 자체 검증은 유지하면서 gpui-kit 0.8.1 조회·다운로드 성공. 전역 설정은 변경하지 않았다.
- 상태: P-5 기본 창 소스와 manifest 작성, 의존성 fetch·첫 빌드 준비 중. 앱 실행·한글 입력·기능 통과를 아직 주장하지 않는다. P-6은 Terra의 정확한 버전 API 조사 진행 중.

## 2026-10-30 — P-5 기본 창 빌드 및 통합 진행

- 명령: `rtk proxy cargo --config http.check-revoke=false info gpui-kit@0.8.1`, 같은 제한 설정의 `fetch` 후 `rtk proxy cargo build --locked --offline` 실행. 첫 빌드는 의존성 캐시가 없는 Windows MSVC 환경, dev profile(debug=0, incremental=false)에서 Cargo 보고 2분33초로 통과했다. 첫 fetch는 800개 패키지를 lock했다(플랫폼 전체 포함, Windows 빌드 수와 구분).
- 실행: 기본 창 실행 파일을 Start-Process로 시작해 PID 23636을 받았다. 프로세스 Responding=True 확인. 초기 창 제목이 비어 있어 화면·한글 입력 검증 증거로 사용하지 않는다. 정상 닫기 요청으로 종료되지 않아 본 검증 프로세스만 종료하고 제목·종료 처리의 통합 창으로 재검증한다. 기존 사용자·Herdr 프로세스는 종료하지 않았다.
- 판단: main이 DECISIONS D-12에서 호출 단위 폐기 확인 우회를 해당 Windows 오류에 한해 수용했다. TLS 인증서 검증 유지, 전역 설정 변경 없음. 이후 호출은 기본 설정 우선, 같은 오류 재현 시만 제한 적용한다.
- 진행: P-7~P-15 관련 코드를 소유 파일별로 작성하고 컴파일 검사 중. 코드를 작성한 사실과 기능 검증 완료를 구분한다. 검사 도구는 main이 target/node_modules/vendor 등 의존성 제외를 반영했으며 `rtk proxy python scripts/check_docs.py`로 Markdown 9개·링크 38개·요구 14개·작업 15개 PASS 확인.
