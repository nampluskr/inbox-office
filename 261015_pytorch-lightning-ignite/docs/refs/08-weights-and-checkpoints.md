# 추론용 가중치와 학습 체크포인트

## 확정된 요구

학습한 모델의 가중치를 저장·복원하여 독립 Predictor에서 사용할 수 있어야 한다.
복원된 모델의 추론에 Lightning·Ignite를 요구하지 않는다.
학습 재개용 체크포인트의 이번 버전 지원 범위는 아직 미정이다.

## 검토 제안: 저장 목적 구분

| 목적 | 저장 후보 | 복원 경로 |
| --- | --- | --- |
| 추론 | 실제 모델 구성요소 가중치, 모델·변환·후처리 설정 | 순수 PyTorch |
| 학습 재개 | 모델, Optimizer, Scheduler, 진행·난수 상태 등 | 해당 백엔드 |

PyTorch는 모델 가중치 복원에 state_dict 방식을 권장한다. 가중치만으로 모델 클래스와
생성 설정이 자동 복원되지는 않는다. 학습 재개에는 가중치 이외의 상태도 필요하다.
[PyTorch 저장·복원 안내](https://docs.pytorch.org/tutorials/beginner/saving_loading_models.html)

추론용 결과물에 학습 Wrapper 전체를 직렬화하여 해당 클래스를 필수 의존성으로 만드는
방식은 피하는 것을 제안한다. native 체크포인트에서 추론용 결과물을 내보내는 방식과
학습 중 별도로 저장하는 방식은 비교가 필요하다.

## 추론용 결과물 후보

아래 이름과 파일 분할은 검토 예시이며 확정 형식이 아니다.

```text
inference-artifact/
├── weights.pt       실제 모델 또는 구성요소별 state_dict
└── metadata.json    모델 생성·변환·후처리 설정
```

| 정보 | 필요한 이유 |
| --- | --- |
| 모델 종류와 생성 인자 | 가중치와 같은 구조의 모델 구성 |
| 구성요소 이름과 가중치 대응 | Encoder/Decoder 등 올바른 대상에 복원 |
| Task와 추론 모드 | 복원·생성·잠재 샘플링 등 동작 구분 |
| 입력 변환 설정 | 채널 순서, 크기, 정규화 재현 |
| 출력·후처리 설정 | 클래스 순서, 임계값, 타깃 역변환 통계 |
| 형식·코드 호환 정보 | 복원 가능한 환경과 변경 여부 판단 |

가중치 state_dict가 transform이나 임의 callable의 코드를 자동 저장한다고 가정하지 않는다.
설정으로 재구성할 수 있는 변환과 별도 구현 코드가 필요한 사용자 정의 함수를 구분한다.
파일별 직렬화 형식, 사용자 정의 함수 등록 방식과 메타데이터 스키마는 미정이다.

## 내보내기와 복원 절차 후보

1. last/best 등 어떤 학습 상태를 내보낼지 명시한다. 최종 메모리 상태를 best로 가정하지 않는다.
2. 실제 모델 또는 구성요소의 가중치와 대응 설정을 저장한다.
3. 학습 백엔드 없이 같은 구조의 모델을 생성한다.
4. 가중치 키·shape 호환을 확인하여 복원한다. 불일치를 조용히 무시하지 않는다.
5. 같은 평가용 입력과 후처리로 저장 전후 결과를 비교한다.

Lightning Wrapper의 접두사가 붙은 전체 state_dict와 순수 모델의 state_dict는 구분해야 한다.
문자열 접두사 제거만으로 모든 저장물을 복원하는 방식을 일반 계약으로 삼지 않고, 내보내는
대상을 명시하는 방향을 제안한다. AE/VAE/GAN은 필요한 구성요소 목록도 함께 확인한다.

## 미정

파일 형식, 메타데이터 스키마, last/best 선택 기본값, 가중치 내보내기 시점, 지원 환경,
학습 재개 기능과 호환성 정책은 미정이다. [독립 Predictor](07-pure-pytorch-predictor.md)와
[검증](10-validation.md)의 요구를 충족하는 형태로 결정해야 한다.
