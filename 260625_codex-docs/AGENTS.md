# AGENTS.md

## 적용 범위
- 이 파일은 저장소 전체에 적용한다.

## 문서 작성 절대 규칙
- 이모지는 사용하지 않는다.
- 마크다운 문서는 UTF-8 인코딩으로 작성하고 저장한다.
- 한글 텍스트가 깨지지 않도록 파일 저장 후 인코딩을 확인한다.

## PLAN 저장 규칙
- Codex가 PLAN 모드에서 `<proposed_plan>`을 제시한 경우, 사용자가 요청하면 해당 계획을 `docs/plans/{YYMMDD-HHMMSS}-{파일내용제목}.md` 파일로 저장한다.
- 사용자가 승인하여 plan이 최종 확정된 경우, Codex는 "최종 확정된 plan을 `docs/plans`에 저장할까요?"라고 사용자에게 묻는다.
- 저장 시 `docs/plans` 폴더가 없으면 생성한다.
- `{YYMMDD-HHMMSS}`는 현재 로컬 시간 기준으로 생성한다.
- `{파일내용제목}`은 계획 내용을 대표하는 짧은 제목으로 만들고, 공백은 하이픈으로 바꾸며 Windows 파일명 금지 문자는 제거한다.
- 저장되는 plan 문서도 UTF-8 인코딩으로 저장하고 한글 깨짐 여부를 확인한다.
- plan 저장은 자동 저장이 아니라, 사용자의 요청 또는 최종 확정 후 사용자 확인을 거쳐 수행한다.
