# AI Agent 작업 방식 가이드

## 문서 목적
이 폴더는 Codex, Claude Code 같은 AI CLI Agent를 단순한 대화 도구가 아니라 개발 작업 파트너로 사용하기 위한 상위 작업 방식을 정리한다.

이 폴더에는 여러 AI Agent 도구에 공통으로 적용되는 사고방식, 작업 설계, 검증, 문서화 흐름을 정리한다.

## 대상 독자
- VS Code Extension의 우측 사이드바에서 Claude Code 또는 Codex를 사용해 본 경험이 있는 사용자
- Python 수치해석, 딥러닝 또는 C++ 알고리즘, 코딩테스트 개발 경험이 있는 사용자
- 앞으로 AI Agent를 이용한 작업 과정을 `docs` 폴더에 체계적으로 문서화하려는 사용자

## AI Agent를 잘 쓰기 위해 배워야 하는 순서
1. AI Agent가 기존 챗봇과 어떻게 다른지 이해한다.
2. Agent가 지켜야 할 작업 환경과 지침을 만든다.
3. 긴 작업에서 컨텍스트, 세션, 메모리를 관리한다.
4. Agent 결과를 믿을 수 있게 검증 기준을 만든다.
5. 권한과 위험 작업을 안전하게 제어한다.
6. 반복 루프와 병렬 작업으로 생산성을 높인다.
7. 모든 과정을 문서와 지식으로 남긴다.

## 가이드 문서 템플릿
`docs/guides` 아래의 개별 가이드 문서는 기본적으로 `docs/guides/TEMPLATE.md`를 사용한다.

이 템플릿은 `초록`, `서론`, 주제별 본론 섹션, `결론`, `참고 자료` 흐름을 따른다. 본론은 `## 본론`이라는 고정 섹션을 만들지 않고, 문서 내용에 맞는 핵심 주제별 `##` 섹션으로 구성한다.

## 작성 우선순위
1. 이 README와 `docs/guides/AGENTS.md`로 전체 문서 구조를 먼저 고정한다.
2. 각 상위 분류 폴더의 `README.md`를 작성해 분류별 범위와 세부 문서 목록을 정한다.
3. 각 분류의 세부 문서는 가이드 문서 템플릿을 기준으로 작성한다.
4. 방법론 설명이 도구별 명령어 설명으로 길어지면 해당 내용은 이 폴더 범위 밖으로 분리한다.
