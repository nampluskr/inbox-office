# Claude Code CLI 매뉴얼

## 문서 목적
이 폴더는 Claude Code CLI를 외부 터미널에서 직접 사용하는 방법을 정리한다.

VS Code Extension 또는 Claude 대화창 사용 경험이 있는 사용자가 CLI 방식으로 프로젝트 작업, 권한 제어, 세션 관리, Git 리뷰를 수행할 수 있도록 구성한다.

## 작성 예정 문서
| 순서 | 파일명 | 내용 |
|---:|---|---|
| 01 | `claude-01-setup.md` | Claude Code 설치, PATH 설정, 버전 확인 |
| 02 | `claude-02-quickstart.md` | 첫 실행, 로그인, 첫 요청 보내기 |
| 03 | `claude-03-interface-modes.md` | Claude 웹, 앱, VS Code Extension, CLI 방식 차이 |
| 04 | `claude-04-command-reference.md` | 자주 쓰는 Claude Code CLI 명령과 옵션 |
| 05 | `claude-05-project-workflow.md` | 프로젝트 폴더에서 파일 읽기, 수정 요청, 결과 확인 |
| 06 | `claude-06-permissions-safety.md` | 권한, 승인, 위험 작업 제어 |
| 07 | `claude-07-session-memory.md` | 세션, 메모리, 컨텍스트 관리 |
