# BRIEF

## 1. 배경

현재 FFT 분석은 사용자가 지정한 ROI를 X축 또는 Y축 방향으로 projection하여 만든
1차원 profile을 대상으로 한다. 이 방식으로 가로 또는 세로 방향의 주기성 라인 얼룩은
확인할 수 있지만, 사선 방향으로 나타나는 주기성 얼룩은 안정적으로 분석하기 어렵다.
현재 분석 결과에는 ROI의 주기성 profile과 FFT Spectrum, Top-K peak가 표시되며,
사용자가 선택한 peak의 주기에 해당하는 주기선이 Profile 그래프에 표시된다. 그러나
같은 주기선이 실제 ROI 영상의 어느 얼룩과 대응하는지는 영상 위에서 직접 확인할 수
없다.

반경이 큰 동심원 형태의 주기성 얼룩은 제한된 ROI 안에서 사선 라인처럼 보일 수 있다.
이 경우 형태만으로 사선과 동심원을 구분하기 어렵고, 동심원의 중심이 영상이나 ROI에서
멀리 떨어져 있어 중심을 직접 찾는 방법도 불안정할 수 있다.

## 2. 이번 버전에서 풀고 싶은 문제

- ROI 안의 사선 방향 주기성 얼룩을 분석하고 싶다.
- ROI 안에서 큰 동심원의 일부로 보이는 주기성 얼룩을 분석하고 싶다.
- 같은 ROI에 사선 분석과 큰 동심원 분석을 각각 적용할 수 있어야 한다.
- 필요하면 두 분석을 함께 적용하고 결과를 나란히 비교할 수 있어야 한다.
- 두 형태가 국소적으로 비슷해 구분하기 어려운 경우에도 어느 한쪽으로 단정하지 않고,
  판단에 필요한 근거와 불확실성을 확인하고 싶다.
- 동심원의 중심이 ROI 또는 영상에서 멀리 떨어진 경우에도 분석 가능성을 검토하고 싶다.
- Profile 그래프와 FFT Spectrum에서 확인한 Top-K peak가 실제 ROI 영상의 어느 반복
  패턴과 대응하는지 직접 확인하고 싶다.
- 선택한 peak의 주기선을 Profile 그래프뿐 아니라 ROI 이미지 위에도 표시하고 싶다.
- 사선 분석과 큰 동심원 분석의 주기선 오버레이를 비교하여 어느 형태가 실제 얼룩을
  더 잘 설명하는지 시각적으로 판단하고 싶다.

## 3. 하지 않을 것

미정.

## 4. 완료 조건

- 동일한 ROI에 사선 주기성 얼룩 분석과 큰 동심원 주기성 얼룩 분석을 각각 적용할 수
  있다.
- 두 분석의 결과를 같은 화면 또는 동일한 기준에서 비교할 수 있다.
- 사선으로 설명되는 정도와 큰 동심원으로 설명되는 정도를 사용자가 구분해 확인할 수
  있다.
- 현재 ROI의 정보만으로 두 형태를 구분하기 어려운 경우, 결과가 그 불확실성을 명시한다.
- 큰 동심원의 중심을 안정적으로 특정할 수 없는 경우에도 분석 결과 전체가 실패하지
  않고, 확인 가능한 범위의 근거를 제공한다.
- ROI마다 주기성 Profile 그래프, FFT Spectrum 그래프와 Top-K peak를 확인할 수 있다.
- Top-K peak를 선택하면 해당 주파수에서 계산된 주기선이 Profile 그래프와 ROI 이미지
  위에 함께 표시되고, 선택을 해제하면 두 위치에서 함께 제거된다.
- 같은 peak는 Profile, FFT Spectrum, Top-K 목록과 ROI 이미지에서 일관되게 식별된다.
- 사선 모델은 ROI 이미지 위에 평행한 사선 주기선을 표시하고, 큰 동심원 모델은 원호
  형태의 주기선을 표시한다.
- 두 형태를 함께 분석할 때 각각의 ROI 이미지 오버레이를 비교할 수 있다.
- 분석 정확도와 형태 판정의 세부 수치 기준은 미정이다.
