# OLED Gray Pattern Mura Inspection - Session Handoff

## 1. 목적

이 문서는 본 세션에서 논의한 OLED 화질 검사 방법론을 별도 프로젝트에서 이어서 실행하기 위한 핸드오프 문서이다.

검사 대상은 OLED 패널에 gray full pattern을 구동한 후 촬영한 휘도 이미지이며, 목표는 2D FFT 기반 분석과 spatial segmentation을 결합하여 얼룩 불량을 검출, 정량화, 위치 표시, 판정하는 것이다.

## 3. 전체 분석 파이프라인

본 세션에서 합의한 기본 파이프라인은 다음과 같다.

```text
원본 촬영 이미지
-> 공통 전처리
-> 불량 유형별 파생 전처리
-> FFT 분석
-> band-pass IFFT defect map 생성
-> spatial segmentation
-> 위치/면적/contrast/grade 판정
```

핵심 분석 항목은 다음 5개이다.

| No. | 항목 | 목적 |
|---:|---|---|
| 1 | 전처리 보정 | 촬영계 artifact를 제거하고 표준 휘도 입력 생성 |
| 2 | radial PSD 기반 mura index | 결함 크기별 비방향성 mura 에너지 정량화 |
| 3 | directional FFT 기반 banding index | 수직/수평 banding 및 line성 결함 정량화 |
| 4 | band-pass IFFT 기반 defect map | 관심 주파수 대역을 공간 defect map으로 복원 |
| 5 | spatial segmentation 기반 판정 | 위치, 면적, contrast, 등급 산출 |

## 7. 전처리 전략

전처리는 공통 전처리와 불량 유형별 파생 전처리로 분리해야 한다.

```text
원본 촬영 이미지
-> 공통 전처리 이미지 L_common
-> 분석 목적별 파생 이미지
```

공통 전처리는 모든 불량 분석에 동일하게 적용한다.

| 공통 전처리 | 목적 |
|---|---|
| dark frame 보정 | 카메라 black level, thermal offset 제거 |
| flat-field 보정 | 렌즈 shading, sensor gain 편차 보정 |
| gamma / linearization | 휘도값을 선형 물리량으로 변환 |
| ROI crop | 패널 영역 추출 |
| perspective / rotation 보정 | 패널 좌표계 정렬 |
| panel mask 생성 | bezel, 외곽, 비표시 영역 제거 |
| saturation / dead pixel 제거 | 촬영 artifact 제거 |
| 평균 휘도 정규화 | gray level, 노출 차이 보정 |
| edge exclusion | edge artifact 또는 chamfer 영역 제외 |
| 데이터 타입 표준화 | float32, normalized luminance 등 |

불량 유형별 파생 전처리는 `L_common`에서 생성한다.

| 분석 대상 | 파생 전처리 목적 |
|---|---|
| global uniformity | 저주파 휘도 편차 보존 |
| cloud / blob mura | 전체 gradient 제거, 중저주파 얼룩 보존 |
| vertical / horizontal banding | 방향성 line 구조 보존 |
| periodic mura | 반복 주파수 성분 보존 |
| fine grain | 고주파 성분 보존 |
| spot / pixel defect | 국소 contrast 강조 |
| color mura | 색채널 또는 색차 성분 분리 |

## 8. FFT 분석 원칙

2D FFT 기반 검사는 불량을 다음 세 관점으로 분해한다.

| 관점 | 설명 | 대표 방법 |
|---|---|---|
| 크기 | 결함의 공간 크기 | radial PSD, band energy |
| 방향성 | 수직/수평/사선 구조 | directional FFT, angular energy |
| 반복성 | 일정 간격 반복 패턴 | spectral peak detection, notch/IFFT |

주요 지표 예시는 다음과 같다.

```text
Low-frequency mura index
Mid-frequency mura index
High-frequency grain index
Vertical band index
Horizontal band index
Anisotropy index
Peak periodicity score
```

## 9. 대표 불량 이미지 생성 계획

각 불량 유형의 대표 gray 이미지는 AI 이미지 생성보다 파이썬 합성 방식이 적합하다. 이유는 불량의 크기, 방향, contrast, 주파수를 수치적으로 제어할 수 있고 FFT 알고리즘 검증에도 사용할 수 있기 때문이다.

권장 출력 구조는 다음과 같다.

    03_blob_mura.png
    04_vertical_banding.png

    08_fine_grain.png

권장 이미지 조건은 다음과 같다.

| 항목 | 권장값 |

## 10. 파이썬 구현 범위

새 프로젝트에서 작성할 파이썬 코드는 다음 모듈 단위가 적합하다.

```text
src/
  preprocessing.py
  fft_radial_psd.py
  fft_directional.py
  fft_bandpass_ifft.py
  segmentation.py
  synthetic_defects.py
  visualization.py
```

초기 구현 우선순위는 다음과 같다.

1. `synthetic_defects.py`: 15개 gray defect sample 및 contact sheet 생성
2. `preprocessing.py`: 공통 전처리 및 파생 전처리 함수 정의
3. `fft_radial_psd.py`: radial PSD 및 mura index 계산
4. `fft_directional.py`: directional FFT 및 banding index 계산
5. `fft_bandpass_ifft.py`: band-pass mask, IFFT defect map 생성
6. `segmentation.py`: threshold, connected components, feature table 생성
