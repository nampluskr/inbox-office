# AGENTS.md 공통 지침

## 공통 참조 폴더 운영 규칙

- 공통 참조 폴더의 기준 경로는 `C:\Users\wonhee.nam\Documents\Codex\_common`이다.
- 참조 문서는 `references`, 반복 프롬프트는 `prompts`, 문서 템플릿은 `templates` 하위 폴더에 보관한다.
- 프로젝트 시작 시 필요한 경우 공통 참조 폴더의 관련 문서를 먼저 확인한다.
- 공통 폴더의 기존 문서를 수정하거나 삭제하기 전에는 사용자에게 확인한다.
- 프로젝트별 임시 파일, 중간 산출물, 결과물은 공통 폴더에 저장하지 않는다.
- 사용자 요청이 있을 때만 공통 폴더에 새 문서나 템플릿을 추가한다.
- 마크다운 문서는 UTF-8 인코딩으로 작성하고 저장한다.
- 이모지는 사용하지 않는다.
