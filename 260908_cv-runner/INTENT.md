# cv-batch-runner

## 무엇을 하는가

사용자가 데이터셋, task, model, backbone, model parameter와 실행 작업을 선택하고, 학습, 평가, 추론 job을 개별 CLI 명령 또는 batch로 실행할 수 있게 한다.

## 왜 하는가

데이터셋과 모델부터 구현한 뒤 CLI와 batch를 덧붙이는 과정에서 task나 model에 따라 실행 방식이 달라지는 문제를 해결한다. 서로 다른 프로젝트에 흩어진 실행 방식을 하나의 일관된 흐름으로 다시 구성하여, 사용자가 실행 조건과 작업 단위를 명확히 이해하고 직접 조합할 수 있게 한다. 동일한 실행 개념을 CLI뿐 아니라 향후 Electron 기반 앱이나 웹 애플리케이션에서도 사용할 수 있게 한다.

## 변하지 않는 원칙

- 데이터셋, task, model, backbone, model parameter와 실행 작업은 사용자가 명시적으로 선택한다.
- model과 backbone은 서로 독립된 선택 항목으로 다룬다.
- 선택 가능한 구성요소와 조합은 사용자가 실행 전에 확인할 수 있어야 한다.
- batch의 각 행은 하나의 독립된 CLI 명령에 대응한다.
- 학습, 평가, 추론은 같은 job 개념과 실행 흐름을 공유한다.
- job 실행과 상태 관리는 AI agent의 판단이나 개입 없이 결정론적으로 동작한다.
- 실행의 핵심 개념은 특정 사용자 인터페이스 기술에 종속되지 않는다.

## 다루지 않는 것

- 데이터셋 자체의 구축과 제공
- model과 backbone 알고리즘 자체의 개발
- AI agent가 job을 선택하거나 실행하고 진행 상태를 판단하는 방식
- 최종 사용자 인터페이스를 Electron 또는 웹 기술 중 하나로 미리 고정하는 일
